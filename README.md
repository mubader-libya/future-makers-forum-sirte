# ملتقى صنّاع المستقبل — العرض التقديمي

عرض تقديمي تفاعلي لملتقى صنّاع المستقبل (طرابلس، يناير 2027): 20 شريحة تروي القصة من سؤال الشباب عن مستقبلهم إلى المجالات الثلاثة، والفعاليات الرئيسية، والمكان، والضجة الإعلامية، والشراكات، والبرنامج السنوي.

## التنقل

| الإجراء | المفتاح |
|---|---|
| الخطوة التالية | السهم الأيسر ← ، المسافة، Enter |
| الخطوة السابقة | السهم الأيمن → |
| أول شريحة / آخر شريحة | Home / End |
| ملء الشاشة | F |
| الهاتف واللوحي | السحب بالإصبع، أو زرّا "التالي" و"السابق" |

زر **الفهرس** في الأعلى يفتح قائمة الشرائح للقفز إلى أي واحدة، ويمكن مشاركة رابط شريحة بعينها، مثل `#s-6`.

## الملفات

- `index.html` — هيكل العرض.
- `deck.css` — التصميم (الوضع الفاتح، ويتكيّف مع الكمبيوتر والهاتف).
- `deck.js` — بناء الشرائح والتنقل.
- `forum-data.js` — كل محتوى العرض في مكان واحد؛ لتعديل نص عدّل هذا الملف فقط.
- `scenes.js` — رسومات أجنحة المكان.
- `img/gen/` — صور تصوّرية مولّدة بالذكاء الاصطناعي، وليست صوراً حقيقية.

## ملاحظات

- الصور تصوّرات فنية، ومكتوب عليها ذلك داخل العرض.
- توزيع القاعات في فندق ريكسوس النصر مقترح، ومبني على بيانات منشورة؛ يحتاج تأكيداً من الفندق.
- لا أسماء لضيوف أو فرق أو جوائز؛ تُعلن مع اعتماد البرنامج.
